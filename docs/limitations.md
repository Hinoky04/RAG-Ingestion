# Limitations

- Text-based PDF and DOCX only; scanned PDFs requiring OCR are outside scope.
- Structural validation is not factual/business correctness.
- The 47-file audit measures structural signals and aggregate repeatability, not retrieval accuracy, MRR, nDCG or semantic completeness.
- Adjusted UI scores are not probabilities or validated confidence.
- Selected table examples do not establish correctness for all layouts.
- PostgreSQL, artifacts and ChromaDB have no common distributed transaction.
- Local data, uploads, model caches and vector state are not tracked.
- No final LLM answer generation, enterprise access control or production deployment.
- FYP release replay, fault attribution and selective recovery belong to the next project.
