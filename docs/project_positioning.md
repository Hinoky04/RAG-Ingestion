# Project Positioning

## What This Repo Is

This repo is a research-intern ingestion MVP.
Its purpose is to demonstrate a clean document-to-vector pipeline for KB-style knowledge.

## What This Repo Is Not

- not a finished chatbot
- not a full enterprise platform
- not a multi-format parser benchmark playground

## Why This Positioning Is Strong

It matches the actual implementation:

- document parsing exists
- validation exists
- PostgreSQL tracking exists
- chunk indexing exists
- retrieval verification exists

That makes the repo more credible than a larger but less honest claim.
