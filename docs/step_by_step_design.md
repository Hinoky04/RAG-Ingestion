# Step-by-Step Design

## Active Pipeline Design

```text
1. Source Registration
2. PDF / DOCX Parsing
3. Conservative Cleaning
4. Canonical JSON + Markdown Preview
5. Chunk Generation
6. Automated Validation
7. PostgreSQL Tracking
8. ChromaDB Indexing
9. Retrieval Verification
```

## Design Principles

- local-first
- easy to explain
- easy to inspect
- defendable intern scope
- traceable outputs
