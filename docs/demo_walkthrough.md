# Demo Walkthrough

## Best Demo Sequence

1. Show a small set of KB Articles files.
2. Upload one document into the workspace.
3. Show the PostgreSQL-tracked document row and validation state.
4. Open the Markdown preview and chunk list.
5. Index the validated document.
6. Run a retrieval query against a known fact.
7. Show the returned chunk, citation metadata, and source traceability.

## What To Emphasize

- the document is tracked, not just parsed
- chunk outputs are inspectable
- indexing is deliberate
- retrieval can be validated against source evidence

## What Not To Overclaim

- final chatbot quality
- semantic correctness guarantees
- production access control
